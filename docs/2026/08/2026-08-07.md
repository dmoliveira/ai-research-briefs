<h2 id="executive-summary">Executive Summary</h2>

The strongest theme this week is that agent capability is inseparable from the harness. <em>Skill-Use</em> shows that even strong models struggle when they must recognize, retrieve, and faithfully follow procedural skills. <em>Argus</em>, <em>ABSeeker</em>, and <em>Scrouting</em> make the same systems point from different angles: long-horizon agents need persistent state, explicit verification, step-level credit, and repository-aware scouting rather than single-shot prompting.

Training and context work also becomes more procedural. <em>Reasoning Core</em> argues that verifiable synthetic data is only useful when generators, targets, difficulty, and scoring are audited. <em>OctoLong</em> shows that code-specific long-context mid-training benefits from dependency-rich contexts built with parsers, language servers, and package managers, not just longer generic documents.

Evaluation papers are practical. <em>Item Response Theory for AI Safety</em> provides a way to reduce, interpret, and audit safety benchmarks, while <em>Provable Limits and Certified Deferral</em> gives small-model deployments a clearer line between calibrated confidence and certified autonomy. Recommender work is narrower but credible, with KDD 2026 and RecSys 2026 accepted papers on exploratory re-ranking and online video recommendation experiments.

<h2 id="key-trends">Key Trends</h2>

<div class="brief-trend-grid">
  <div class="brief-trend-card"><p><strong>Agent skills are now an evaluation target.</strong></p><p>Skill triggering, procedural compliance, and boundary following are being measured directly instead of hidden inside aggregate task success.</p></div>
  <div class="brief-trend-card"><p><strong>Repository agents need scouting before editing.</strong></p><p>Scrouting and RepoProbe both push against premature code edits by making repository exploration and architecture evidence first-class.</p></div>
  <div class="brief-trend-card"><p><strong>Long-context training is becoming domain engineered.</strong></p><p>OctoLong treats code context as dependency structure assembled by tools, not as raw long text.</p></div>
  <div class="brief-trend-card"><p><strong>Safety evaluation is becoming psychometric.</strong></p><p>IRT-style benchmark modeling and certified deferral both separate score reporting from deployment decisions.</p></div>
  <div class="brief-trend-card"><p><strong>Agent memory is being optimized for cost.</strong></p><p>MemoryCPT and HiGram focus on retrieving less irrelevant history, rewriting localized memory paths, and measuring quality per cost.</p></div>
  <div class="brief-trend-card"><p><strong>LLM infrastructure now touches energy operations.</strong></p><p>Chunked prefill scheduling appears as a power-ramp control knob, not only a latency optimization.</p></div>

    <div class="entry-section"><p><span class="entry-section-title">Summary</span>Skill-Use evaluates whether an agent can recognize a relevant skill from its name and description, retrieve the full procedure, comply with it, and avoid forbidden operations.</p></div>

    <div class="entry-section"><p><span class="entry-section-title">My take</span>This should be read by anyone building skill libraries for agents: the instruction file is not useful unless the harness makes the model fetch and obey it.</p></div>

  <h3>ABSeeker: Training Long-Horizon Search Agents via Answer-Backtracked Credit Assignment</h3>
  <p class="entry-summary">A training framework that turns sparse final-answer supervision into step-level credit for search, retrieval, verification, and evidence integration.</p>
  <div class="entry-meta-grid">
    <div class="entry-meta-item"><span class="entry-meta-label">Published / updated</span><span>2026-08-05 / 2026-08-05; arXiv ID 2608.05102</span></div>
    <div class="entry-meta-item"><span class="entry-meta-label">Authors</span><span>Yijun Lu, Rui Ye, Jiajun Wang, Yuwen Du, Tian Jin, Songhua Liu, Siheng Chen</span></div>
    <div class="entry-meta-item"><span class="entry-meta-label">Affiliations</span><span>Not listed in arXiv metadata</span></div>
    <div class="entry-meta-item"><span class="entry-meta-label">Link</span><span><a class="entry-link" href="https://arxiv.org/abs/2608.05102">https://arxiv.org/abs/2608.05102</a></span></div>
    <div class="entry-meta-item"><span class="entry-meta-label">Tags</span><span>search agents, reinforcement learning, credit assignment, BrowseComp</span></div>
    <div class="entry-meta-item"><span class="entry-meta-label">Reading profile</span><span>28-42 min - Relevance 5/5 - Quality 4/5</span></div>
  </div>
  <div class="entry-section-grid">
    <div class="entry-section"><p><span class="entry-section-title">Summary</span>ABSeeker uses answer-backtracked clue recovery and clue-anchored step scoring to reward useful search actions and suppress redundant or erroneous ones.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">Problem investigated</span>Search-agent training often treats every step in a successful trajectory as good and every failed trajectory as bad, wasting useful partial evidence.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">Context</span>Long-horizon web and evidence agents need dense supervision for when search, verification, and integration steps actually contributed.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">Solutions explored</span>The framework produces step scores from recovered answer clues, then applies them through ABC-SFT and ABC-GRPO on a Qwen3.5-4B base.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">Key results</span>With 8.5k examples, ABSeeker reports 37.3% on BrowseComp and 39.1% on BrowseComp-ZH; with context management, scores rise to 55.3% and 52.9%.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">Conclusion</span>Answer-level supervision can be made more useful by tracing back which intermediate clues should have shaped the search trajectory.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">My take</span>The useful idea is not just the agent score; it is the decomposition of final-answer success into training signal for individual evidence actions.</p></div>
  </div>
</article>

  <h3>OctoLong: Mid-Training On Cross-Repository Code Contexts Enhances Long-Context Modeling</h3>
  <p class="entry-summary">A code-context engineering pipeline that builds dependency-rich million-token contexts for long-context model mid-training.</p>
  <div class="entry-meta-grid">

    <div class="entry-meta-item"><span class="entry-meta-label">Authors</span><span>Indraneil Paul, Falko Helm, Goran Glavas, Iryna Gurevych</span></div>
    <div class="entry-meta-item"><span class="entry-meta-label">Affiliations</span><span>Not listed in arXiv metadata</span></div>
    <div class="entry-meta-item"><span class="entry-meta-label">Link</span><span><a class="entry-link" href="https://arxiv.org/abs/2608.05141">https://arxiv.org/abs/2608.05141</a></span></div>

    <div class="entry-meta-item"><span class="entry-meta-label">Reading profile</span><span>35-55 min - Relevance 5/5 - Quality 5/5</span></div>
  </div>
  <div class="entry-section-grid">
    <div class="entry-section"><p><span class="entry-section-title">Summary</span>OctoLong recursively retrieves code references with an AST parser, language server backend, and package manager to create dependency-rich contexts for context-extension mid-training.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">Problem investigated</span>Generic long-context corpora often lack the long-distance dependencies needed for repository-scale coding and agentic workflows.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">Context</span>Long-context code agents need models that can track APIs, dependencies, and state across repositories, not just retrieve facts from long documents.</p></div>

    <div class="entry-section"><p><span class="entry-section-title">Key results</span>Replacing 12% of traditional context-extension data with OctoLong data improves long-range retrieval, long-term state tracking, repository-level code understanding, downstream agentic tasks, and short-context API usage.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">Conclusion</span>Long-context training data quality depends on domain-specific dependency structure, not only token length.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">My take</span>This is one of the best practical papers of the week because it connects code-agent performance to how the long-context corpus is assembled.</p></div>
