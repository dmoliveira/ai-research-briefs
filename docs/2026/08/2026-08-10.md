<h2 id="executive-summary">Executive Summary</h2>

This week is unusually strong for agent infrastructure. <em>The Bitter Lesson of Tool Calling</em> directly compares programmatic tool calling with JSON-style tool APIs and finds that typed code stubs often match or beat native JSON tool calls, especially under parallel fan-out and context rot. <em>HarnessOpt-Bench</em> turns harness improvement itself into an evaluated capability, making prompts, tools, control flow, memory, and orchestration part of the benchmarked surface rather than hidden implementation detail.

Agent reliability work is also becoming more diagnostic. <em>TRAJDEBUG</em> traces error lifecycles through long failed trajectories, while <em>When History Lies</em> isolates a common persistent-agent failure: old but plausible tool traces corrupt current tool-use decisions. <em>EnvACE</em> and <em>AppDeltaWorld</em> both push agent training away from expensive real-environment interaction by using internal or generated world models, with different risk profiles.

Retrieval and evidence papers are practical. <em>Beyond Top-K</em> argues that table-heavy financial documents need deterministic search and span-reading operations, not opaque nearest-neighbor chunks. <em>HERALD</em> shows that proof-of-retrieval rewards can be hacked through citation laundering unless their detector contracts are audited. Recommender work is strong on production simplification and evidence standards: <em>Gryphon-v2</em> replaces a multi-stage Yandex Music cascade with a single generate-and-rank model, while the multimodal weighting audit challenges common personalization claims.

<h2 id="key-trends">Key Trends</h2>

<div class="brief-trend-grid">
  <div class="brief-trend-card"><p><strong>Tool interfaces are becoming a benchmark variable.</strong></p><p>Programmatic tool calls, tool-history pollution, and harness optimization all show that the wrapper can dominate the apparent model capability.</p></div>
  <div class="brief-trend-card"><p><strong>Agent failures are being traced, not just scored.</strong></p><p>Trajectory debugging, proof-of-retrieval audits, and history-pollution benchmarks decompose success into evidence, state, and attribution.</p></div>
  <div class="brief-trend-card"><p><strong>World models are entering agent training loops.</strong></p><p>EnvACE internalizes tool-response dynamics; AppDeltaWorld generates transition-grounded mobile GUI states for closed-loop data and test-time adaptation.</p></div>
  <div class="brief-trend-card"><p><strong>Retrieval work is moving past top-k embeddings.</strong></p><p>The strongest retrieval papers focus on exclusion semantics, deterministic document operations, and auditable evidence records.</p></div>
  <div class="brief-trend-card"><p><strong>Personalization claims need counterfactual controls.</strong></p><p>The multimodal recommender audit shows that shuffled-user tests alone can overstate per-user personalization.</p></div>
  <div class="brief-trend-card"><p><strong>Industrial recsys papers are simplifying serving graphs.</strong></p><p>Gryphon-v2 is notable because it reports a production A/B lift while replacing a cascade, not just improving an offline metric.</p></div>

  <p class="entry-summary">A benchmark and training method for tool-call agents whose old but plausible histories corrupt current state decisions.</p>
  <div class="entry-meta-grid">

    <div class="entry-meta-item"><span class="entry-meta-label">Authors</span><span>Xiaoqing Wu, Xingyu Fan, Feifei Li, Wenhui Que</span></div>
    <div class="entry-meta-item"><span class="entry-meta-label">Affiliations</span><span>Not listed in arXiv metadata</span></div>
    <div class="entry-meta-item"><span class="entry-meta-label">Link</span><span><a class="entry-link" href="https://arxiv.org/abs/2608.06057">https://arxiv.org/abs/2608.06057</a></span></div>
    <div class="entry-meta-item"><span class="entry-meta-label">Tags</span><span>tool use, multi-turn agents, history pollution, state tracking, distillation</span></div>

  </div>
  <div class="entry-section-grid">
    <div class="entry-section"><p><span class="entry-section-title">Summary</span>The paper creates paired Original, Polluted, and Oracle State views to test whether agents can ignore stale or misleading historical traces while preserving current tool policy.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">Problem investigated</span>Persistent agents accumulate dialogue and tool histories that can stay syntactically valid after they stop being authoritative for the latest request.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">Context</span>Long-running product agents often reuse old entities, API conventions, or state assumptions when the environment changes.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">Solutions explored</span>The authors isolate failures in decision state, entity binding, and interface execution, then transfer an Oracle-conditioned teacher policy to a student observing polluted history.</p></div>

    <div class="entry-section"><p><span class="entry-section-title">Conclusion</span>History reliability is a distinct tool-use bottleneck, and reliable-state policy transfer can improve robustness without handing the student oracle state at inference.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">My take</span>This maps cleanly to production agents: memory and transcript retention need validity boundaries, not just more context.</p></div>
