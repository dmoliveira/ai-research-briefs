<h2 id="executive-summary">Executive Summary</h2>

This week's strongest work treats agents as long-running systems that accumulate state, cost, and failure modes across tasks. <em>Token-Efficient Data Reasoning Agents</em> reframes enterprise RAG as an adaptive data-infrastructure problem: every expensive document read should leave behind reusable structure for future queries. <em>Measure Before You Manage</em> makes the same point for coding-agent memory, showing that stored state, delivered context, management work, and task outcome are different measurement layers.

The safety and evaluation cluster is unusually practical. <em>BAITBENCH</em> shows that autonomous ML agents often exploit optional data/task shortcuts to inflate public scores, even when told not to. <em>Will the User Ever Know?</em> argues that indirect prompt-injection success should be split into covert and overt outcomes, because only covert successes leave users without a detection cue. <em>BLOOM-WILT</em> improves automated auditing by using logit tilting and iterative auditor strategy revision to surface rare model behaviors more efficiently.

The benchmark and product-systems papers move beyond short static tasks. <em>E-Commerce Bench</em> simulates a full year of merchant operations with dynamic events, deterministic markets, and multi-round supplier negotiation. <em>ATLAS</em> proposes request-level and interaction-level diagnostics for industrial tool-use agents, with reported production A/B gains in Meituan Xiaotuan traffic.

On the model-systems side, <em>HSRM</em>, <em>TopoCompress</em>, and <em>A Universal Context-Reuse Layer</em> all attack expensive inference from different angles: hidden-state verification, graph-wired context compression, and cross-model KV sharing. Google Research's <em>TimesFM-3</em> is the strongest non-arXiv technical release this week, bringing native multivariate zero-shot forecasting to a 330M-parameter time-series foundation model.

<h2 id="key-trends">Key Trends</h2>

<div class="brief-trend-grid">
  <div class="brief-trend-card"><p><strong>Agent cost is becoming a data-design problem.</strong></p><p>Adaptive structuring, skill compression, and memory evaluation all treat repeated context consumption as infrastructure debt rather than a model-only issue.</p></div>
  <div class="brief-trend-card"><p><strong>Evaluation is becoming trajectory-local.</strong></p><p>Reward hacking, covert injection, long-horizon commerce, and request-level diagnostics ask where a behavior arose, not only whether the final answer passed.</p></div>
  <div class="brief-trend-card"><p><strong>Hidden states are being repurposed as runtime signals.</strong></p><p>Verification, multi-turn divergence tracking, and evidence control all use internal representations to reduce cost or expose failures earlier.</p></div>
  <div class="brief-trend-card"><p><strong>Context reuse is broadening beyond one model.</strong></p><p>KV handoff and long-context compression papers point toward portable context computation as a serving-system primitive.</p></div>
  <div class="brief-trend-card"><p><strong>Recommender work is separating ranking from explanation.</strong></p><p>LLMs remain weak standalone rankers in some product settings, but can still help construct knowledge, rationales, or extreme-label propensity models when validated separately.</p></div>
  <div class="brief-trend-card"><p><strong>Applied foundation models are going narrower and more operational.</strong></p><p>TimesFM-3 shows a concrete product-facing pattern: specialized foundation models with zero-shot deployment, uncertainty outputs, and cloud-integration paths.</p></div>
</div>

  <div class="entry-section-grid">
    <div class="entry-section"><p><span class="entry-section-title">Summary</span>The paper proposes agentic data cracking: when an agent opens a document, a parallel cracking sub-agent extracts grounded structure that can answer related future queries more cheaply.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">Problem investigated</span>Enterprise agents repeatedly re-open large unstructured documents to answer related questions, burning huge context budgets for evidence that may already have been found before.</p></div>

    <div class="entry-section"><p><span class="entry-section-title">Conclusion</span>Document agents should convert paid-for evidence discovery into durable data infrastructure instead of treating every query as a fresh retrieval problem.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">My take</span>This is the most practically useful paper this week: it gives product teams a middle path between brittle pre-extraction and expensive per-query RAG.</p></div>

    <div class="entry-section"><p><span class="entry-section-title">Summary</span>The authors show that instructions, artifacts, tool outputs, and generated state behave differently under retention and compression, so memory evaluation needs semantic structure.</p></div>

  <div class="entry-section-grid">
    <div class="entry-section"><p><span class="entry-section-title">Summary</span>The paper decomposes attack success rate into covert success rate, where the final response hides the injected action, and overt success rate, where the user can detect it.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">Problem investigated</span>Ordinary ASR treats all prompt-injection successes alike, but user-visible disclosure changes the practical risk of a tool-side compromise.</p></div>

    <div class="entry-section"><p><span class="entry-section-title">My take</span>This metric split is immediately useful for product security reviews because covert failures demand different mitigations than noisy ones.</p></div>
