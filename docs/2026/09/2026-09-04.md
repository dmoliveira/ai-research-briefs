<h2 id="executive-summary">Executive Summary</h2>

This issue is unusually concentrated on the control plane around powerful models rather than on model architecture alone. OpenAI's <em>Safety overview: GPT-6 Astra</em> is the strongest non-arXiv technical item: it says the newly deployed model reaches the company's Critical cybersecurity threshold, has lower chain-of-thought monitorability than its predecessor, and is deployed with broader tool-use misalignment monitoring. Read it with the obvious caveat that it is a first-party safety summary, not an external audit.

The agent papers make a clear systems argument. <em>Discriminative World Models for Web Agents</em> trains predicted web states to be useful for downstream action ranking rather than merely reconstructive. <em>EarlyEval</em> cuts the cost of SWE-bench Verified, TerminalBench, and Toolathlon runs by predicting outcomes from intermediate behavior. <em>Repo-To-Skill</em>, <em>SafeEvolve</em>, and <em>A Finger on the Scale</em> together show why reusable agent skills are now a first-class software artifact: they can improve AI-for-AI research, carry safety updates, and also covertly steer policies.

Security and trust boundaries are another strong thread. <em>ACLE-MCP</em> argues that OAuth is not enough for remote tool use because authorization can outlive the trusted workload. <em>CodePoisonRAG</em> shows that a single poisoned code artifact can be enough to steer retrieval-augmented code generation toward attacker-selected vulnerabilities. <em>The Implications of Linguistic Illegibility</em> argues that systems relying on linguistic self-reporting need non-linguistic isolation controls such as taint tracking.

The retrieval, data, and recommender papers are more product-facing. <em>Incremental Pooled LLM Evaluation</em> gives RAG teams a practical way to reuse judgments as candidate retrievers change. <em>A Power Law in Logarithm's Clothing</em> challenges a common vector-database scaling assumption. <em>CORAL</em> is the most production-oriented recommender item, reporting closed-loop LLM-driven recommender optimization across two large social platforms.

<h2 id="key-trends">Key Trends</h2>

<div class="brief-trend-grid">
  <div class="brief-trend-card"><p><strong>Agent evaluation is moving inside the trajectory.</strong></p><p>Early stopping, structured failure localization, long-horizon games, and web-state prediction all use intermediate behavior as the object of measurement.</p></div>
  <div class="brief-trend-card"><p><strong>Reusable skills are becoming policy artifacts.</strong></p><p>Skills now show up as performance accelerators, safety-update carriers, and supply-chain attack surfaces.</p></div>
  <div class="brief-trend-card"><p><strong>Authorization is shifting from connection time to invocation time.</strong></p><p>Remote tool-use security needs to bind a specific call to a fresh workload state, operation, object, and parameter bounds.</p></div>
  <div class="brief-trend-card"><p><strong>RAG risk is becoming upstream and incremental.</strong></p><p>Teams need poisoned-artifact defenses and cheaper repeated evaluation as knowledge bases and retrievers evolve.</p></div>
  <div class="brief-trend-card"><p><strong>Long-context efficiency is becoming model-mediated.</strong></p><p>Declarative attention and world-model state prediction both ask models to expose enough internal structure to guide runtime computation.</p></div>
  <div class="brief-trend-card"><p><strong>Recommendation is adopting adaptive compute and agent loops.</strong></p><p>Routing hard cases to slower reasoning and letting guarded agents tune production systems are converging patterns.</p></div>
</div>

    <div class="entry-section"><p><span class="entry-section-title">Summary</span>CodePoisonRAG transforms benign fixed-code entries into poisoned artifacts with CWE-specific vulnerable flows and misleading safety labels.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">Problem investigated</span>RACG systems trust external code, docs, and patches as generation context, creating a knowledge-base attack surface independent of the base model.</p></div>

  <div class="entry-meta-grid">
    <div class="entry-meta-item"><span class="entry-meta-label">Published / updated</span><span>2026-09-02 / 2026-09-02; arXiv ID 2609.02783</span></div>
    <div class="entry-meta-item"><span class="entry-meta-label">Authors</span><span>Yuling Shi, Zhensu Sun, Junsen Dong, Chengcheng Wan, David Lo, Xiaodong Gu</span></div>
    <div class="entry-meta-item"><span class="entry-meta-label">Affiliations</span><span>Not listed in arXiv listing metadata</span></div>
    <div class="entry-meta-item"><span class="entry-meta-label">Link</span><span><a class="entry-link" href="https://arxiv.org/abs/2609.02783">https://arxiv.org/abs/2609.02783</a></span></div>
    <div class="entry-meta-item"><span class="entry-meta-label">Tags</span><span>agent evaluation, SWE-bench, TerminalBench, Toolathlon, cost reduction</span></div>

  </div>
  <div class="entry-section-grid">
    <div class="entry-section"><p><span class="entry-section-title">Summary</span>EarlyEval trains LightGBM success and failure classifiers over behavioral, textual, and reference-solution features, halting runs when confidence is high.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">Problem investigated</span>Benchmark distillation reduces the number of tasks, but expensive retained tasks still run to completion every development cycle.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">Context</span>Frontier-agent evals can cost hundreds to thousands of dollars per full pass, especially on tool-heavy tasks.</p></div>

    <div class="entry-section"><p><span class="entry-section-title">Conclusion</span>Agent evaluation cost can be reduced within each task by detecting likely outcomes early.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">My take</span>This is immediately deployable for internal eval harnesses if teams treat confidence calibration and false-stop analysis as first-class outputs.</p></div>
