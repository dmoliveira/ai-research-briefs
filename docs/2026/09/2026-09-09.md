<h2 id="executive-summary">Executive Summary</h2>

This week is unusually coherent: agent systems are being treated less like prompt wrappers and more like stateful software platforms. <em>CUA-Universe</em> is the clearest infrastructure paper, turning real desktop software into hybrid GUI+CLI environments and showing large efficiency gains when agents learn to coordinate both surfaces. <em>Does Your Agent's Memory Survive a Model Upgrade?</em> is the practical counterpart: memory stores that appear stable can degrade after model swaps unless raw histories, embedding-space isolation, and migration tests are preserved.

Trace reuse is another major theme. <em>Trace2Tower</em> turns successful execution traces into hierarchical skill towers, while <em>TROVE</em> edits only invalidated route suffixes instead of replanning entire workflows. <em>Substrate-Aware AI Agents</em> shows that simply disclosing memory and time budgets can push frontier code models toward materially different implementations. The common message is that agent behavior depends heavily on execution context, trace topology, and state representation.

Evaluation work continues to move beyond superficial success. <em>TruthInsightBench</em> distinguishes executing a prescribed analysis from making a defensible scientific claim. <em>KOPA-Bench</em> tests multi-step tool calling over live Korean public APIs, and the automated program repair hallucination study shows that test-passing patches can still be ungrounded. These papers are valuable because they expose failure modes that ordinary leaderboards flatten.

On the systems side, <em>Same Request, Different Answer</em> is a useful warning about prefix-cache state and quantization in LLM serving. <em>Don't Drop Dropout</em> revives layer dropout as a scaling recipe for both training and inference efficiency, while <em>RISE</em> proposes dense token supervision from a model's own RLVR trajectory. Retrieval and recommender papers are strongly production-facing, with adaptive embedding edits, compressed RAG contexts, inventory-grounded AI search, multimodal Doc2Query, and atomic memory for agentic recommendation.

<h2 id="key-trends">Key Trends</h2>

<div class="brief-trend-grid">
  <div class="brief-trend-card"><p><strong>Agents need environment infrastructure, not just better prompts.</strong></p><p>Hybrid GUI+CLI environments, execution contracts, live APIs, and reusable trajectories are becoming first-class design objects.</p></div>
  <div class="brief-trend-card"><p><strong>Memory portability is now a migration problem.</strong></p><p>Model upgrades can change note interpretation, embedding retrieval, and repairability unless source histories are retained.</p></div>
  <div class="brief-trend-card"><p><strong>Trace-derived skills are maturing.</strong></p><p>Several papers mine prior rollouts into skill hierarchies, transition graphs, or editable route plans instead of treating logs as passive analytics.</p></div>
  <div class="brief-trend-card"><p><strong>Serving optimizations can affect reproducibility.</strong></p><p>Prefix-cache state and quantization can shift multi-turn trajectories even under fixed prompts, seeds, and request order.</p></div>
  <div class="brief-trend-card"><p><strong>RAG is optimizing both evidence coverage and context cost.</strong></p><p>Adaptive planning, topology-aware evidence reuse, dense-embedding edits, and soft context compression target different bottlenecks in retrieval-augmented systems.</p></div>
  <div class="brief-trend-card"><p><strong>Recommender work is turning operational constraints into model signal.</strong></p><p>Inventory state, category complementarity, commercial objectives, and evolving memory structures are being built into retrieval and ranking loops.</p></div>

  <h3>TROVE: Adaptive Agent Skill Orchestration via Trace-Grounded Route Validation and Editing</h3>
  <p class="entry-summary">An adaptive orchestration method that edits only the invalidated part of a planned skill route after runtime evidence arrives.</p>
  <div class="entry-meta-grid">
    <div class="entry-meta-item"><span class="entry-meta-label">Published / updated</span><span>2026-09-04 / 2026-09-04; arXiv ID 2609.05019</span></div>
    <div class="entry-meta-item"><span class="entry-meta-label">Authors</span><span>Tianxing Wang, Mingming Zhao, Shuai Huang, Huiyang Xu, Chaoyue Niu, Shengzhong Liu, Fan Wu</span></div>
    <div class="entry-meta-item"><span class="entry-meta-label">Affiliations</span><span>Not listed in arXiv listing metadata</span></div>
    <div class="entry-meta-item"><span class="entry-meta-label">Link</span><span><a class="entry-link" href="https://arxiv.org/abs/2609.05019">https://arxiv.org/abs/2609.05019</a></span></div>
    <div class="entry-meta-item"><span class="entry-meta-label">Tags</span><span>agent orchestration, route editing, skill graphs, workflow search, efficiency</span></div>
    <div class="entry-meta-item"><span class="entry-meta-label">Reading profile</span><span>25-35 min - Relevance 5/5 - Quality 4/5</span></div>
  </div>
  <div class="entry-section-grid">
    <div class="entry-section"><p><span class="entry-section-title">Summary</span>TROVE distills evaluated workflow-search traces into skills and transition graphs, then selectively validates, inserts, or replaces route suffixes during execution.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">Problem investigated</span>Agents often commit to execution structures before decisive evidence is available, then either follow stale plans or replan too broadly.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">Context</span>Skill-routing and graph-constrained agent systems can improve efficiency but become brittle when intermediate outcomes invalidate earlier assumptions.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">Solutions explored</span>The method preserves valid route prefixes, inserts trace-supported local responses, and replaces only invalid continuations.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">Key results</span>Across code-generation, QA, and math reasoning benchmarks, TROVE reports a better quality-efficiency trade-off than dataset-level optimization, architecture selection, and graph scheduling baselines.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">Conclusion</span>Selective route editing is a useful control principle for adaptive agent workflows.</p></div>
    <div class="entry-section"><p><span class="entry-section-title">My take</span>This is a pragmatic middle ground between rigid plans and expensive full replanning; the operational question is how well the route validator holds up under noisy evidence.</p></div>
